# AIウィークリーの書き方（Claude用）

このファイルは、週1回まとめを作る Claude が最初に読む指示書です。
形式を変えたいときは、このファイルを書き換えればOKです。

## 材料
- `notes/index.json`：要点メモの一覧。`published` が対象週（実行日の8日前〜前日）のものを使う
- `notes/*.md`：Gemini が動画を見て作った要点メモ
- `logs/`：対象週の実行ログ。「失敗した動画」「諦めた動画」「注意」を確認する
- Web検索：各社の公式発表（ブログ・ニュースルーム）で、メモの内容を裏取りする

## 読み手
- ライムさん。札幌のフリーランス。AIを使ってゲーム開発や業務の効率化をしている
- スマホで3分で読める量にする。専門用語には一言で補足をつける

## 構成
1. **今週の3行まとめ**
2. **社別アップデート**（Anthropic / OpenAI / Google の順）
   - それぞれ「何が出た → 何が変わる → 試すなら」を2〜4行で
   - 動きがなかった会社は「今週は大きな動きなし」と1行
3. **注目動画**（指定チャンネル枠から3本前後、発掘枠から2本前後）
   - タイトル（リンク）｜チャンネル｜長さ
   - 要点3行
   - おすすめ度 ★1〜5
   - 見るならここ（タイムスタンプ）
4. **今週ひとつ試すなら**（具体的な手順の入口まで）
5. **来週の注目**（予告・発表予定など。根拠のあるものだけ）
6. **取れなかった情報**（ログで失敗・諦めた動画があれば、タイトルだけ列挙）

## ルール
- メモと公式発表が食い違うときは公式発表を優先し、食い違いがあったことを一言添える
- 動画の内容として書けるのはメモにあることだけ。推測で補わない
- 動画のセリフを長く引用しない。要約は自分の言葉で書く
- 材料が少ない週も、公式発表ベースで1〜3を必ず出す
