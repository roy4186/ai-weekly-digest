# AIウィークリーの書き方（Claude用）

毎週土曜の朝にまとめを作る Claude が最初に読む指示書です。
形式を変えたいときは、このファイルを書き換えればOKです（次の土曜から反映）。

## 届け先
- Notion のデータベース「AIウィークリー」
  - データソース：collection://639e87da-bf34-4c87-97ca-84ece50bab1d
  - 1週間につき1ページを追加する

## 対象週
- 実行日（土曜）の前日までの7日間。前の週の土曜〜金曜

## 材料
- `notes/index.json`：要点メモの一覧。`published` が対象週のものを使う
- `notes/*.md`：Gemini が動画を見て作った要点メモ
- `logs/`：対象週の実行ログ。「失敗した動画」「諦めた動画」「注意」を確認する
- Web検索：各社の公式発表（ブログ・ニュースルーム・公式X）で、メモの内容を裏取りする

## 読み手
- ライムさん。プログラミング未経験から、AIを使ってゲーム開発や業務の効率化をしている
- スマホで3分で読める量にする。専門用語には一言で補足をつける

## プロパティ
| 名前 | 入れるもの |
|---|---|
| タイトル | `AIウィークリー M/D〜M/D` |
| 週 | 対象週の初日〜最終日（日付の範囲） |
| ひとこと | 今週を一言で（40字以内） |
| 動いた会社 | 大きな動きがあった会社（Anthropic / OpenAI / Google / その他） |
| 動画数 | まとめに使った動画メモの本数 |
| 取れなかった動画 | ログで失敗・諦めた動画の本数 |
| 状態 | 完成（動画メモ5本以上）／材料少なめ（1〜4本）／収集停止（0本、または収集が止まっている） |
| 既読 | 触らない（ライムさんが使う） |

ページのアイコンは 📰。

## 本文の構成
1. **今週の3行まとめ**（コールアウト）
2. **社別アップデート**（Anthropic → OpenAI → Google の順）
   - それぞれ「何が出た → 何が変わる → 試すなら」を2〜4行で
   - 動きがなかった会社は「今週は大きな動きなし」と1行
3. **注目動画**（指定チャンネルから3本前後、発掘枠から2本前後。おすすめ度の高い順）
   - 見出し：動画タイトル（リンク）
   - 1行目：チャンネル｜長さ｜おすすめ度 ★1〜5
   - 要点3行
   - 見るならここ（タイムスタンプ）
4. **今週ひとつ試すなら**（具体的な手順の入口まで）
5. **来週の注目**（予告・発表予定など。根拠のあるものだけ）
6. **その他の動画**（トグルの中に、残りの動画を「タイトル（リンク）｜チャンネル｜★」の1行ずつ）
7. **取れなかった情報**（ログで失敗・諦めた動画のタイトル。なければ省略）
8. **出典**（裏取りに使った公式発表のリンク）

## ルール
- メモと公式発表が食い違うときは公式発表を優先し、食い違いがあったことを一言添える
- 動画の内容として書けるのはメモにあることだけ。推測で補わない
- 動画のセリフを長く引用しない。要約は自分の言葉で書く
- 材料が少ない週も、公式発表ベースで1・2・4を必ず出す
